# 귀여운 마스크 재디자인 계획

## 목표

현재 나비·나뭇잎·구름 마스크를 초등학생이 작은 선택 아이콘과 큰 워드 클라우드 양쪽에서 즉시 알아볼 수 있는 둥글고 친근한 실루엣으로 다시 그린다. 전구와 기존 마스크, 단어 배치·PNG 저장 동작은 유지한다.

## 레퍼런스 조사

- [wordcloud.kr v1](https://wordcloud.kr/v1)의 `fly` 마스크: 정면 대칭, 큰 위 날개와 작은 아래 날개, 깊은 옆 허리, 가는 몸통과 더듬이가 핵심이다.
- [wordcloud.kr v1](https://wordcloud.kr/v1)의 `cloud` 마스크: 적은 수의 둥근 봉우리와 안정적인 아랫선으로 작은 크기에서도 구름으로 읽힌다.
- [OpenMoji 나비](https://openmoji.org/library/emoji-1F98B/), [OpenMoji 잎](https://openmoji.org/library/emoji-1F343/), [OpenMoji 스타일 가이드](https://www.openmoji.org/styleguide/): 유기적인 곡선, 강한 중심축, 세부 묘사의 절제를 참고한다.
- [Twemoji](https://github.com/twitter/twemoji)와 [Emoji Family 나비 비교](https://www.emoji.family/emojis/animals-nature/butterfly): 여러 플랫폼에서 반복되는 네 날개·중앙 몸통·더듬이 구조를 비교한다.
- Google Noto, Icons8 Cute Outline, Canva·Rawpixel의 아동용 스티커 레퍼런스: 굵고 단순한 외곽, 한 개의 큰 주형과 적은 보조 곡선, 작은 크기에서도 구분되는 비례를 참고한다.

레퍼런스 이미지를 직접 복제하지 않고, 위 공통 특징을 새 Canvas Bézier 곡선과 SVG 아이콘으로 재구성한다.

## 프런트엔드 디자인 기준

- **Visual thesis:** 교과서에 붙이는 동화 스티커처럼 둥글고 부드럽지만, 한눈에 사물을 알아볼 수 있는 또렷한 실루엣.
- **Content plan:** 큰 캔버스 외곽선이 형태를 설명하고, 내부 선은 몸통·잎맥처럼 인식에 꼭 필요한 정보만 보조하며, 설정 아이콘은 같은 실루엣을 축소해 보여 준다.
- **Interaction thesis:** 기존 즉시 다시 그리기와 선택 상태를 유지하고, 새로운 장식 애니메이션은 추가하지 않는다. 중요한 `워드 클라우드 만들기` 강조 효과와 키보드 접근성도 그대로 유지한다.

## 형태별 설계

### 나비

- 위 날개는 크고 둥글게, 아래 날개는 작고 물방울처럼 만든다.
- 위·아래 날개 사이의 옆 허리를 현재보다 깊게 파서 리본 모양으로 보이지 않게 한다.
- 중앙 몸통은 머리–몸통–꼬리의 세로축으로 분명히 보이고, 짧게 휘는 더듬이 두 개를 둔다.
- 좌우는 엄격하게 대칭을 유지한다.

### 나뭇잎

- 오른쪽 위를 향하는 뾰족한 끝과 왼쪽 아래로 이어지는 잎자루를 하나의 흐름으로 만든다.
- 잎몸은 단순한 타원이 아니라 끝과 밑동이 좁아지는 렌즈형 곡선으로 만든다.
- 중앙 잎맥은 잎자루와 이어지고, 짧은 곁맥 3~4개만 둔다.
- 단어 배치 영역은 잎몸 내부의 연결된 안전 영역 하나로 유지한다.

### 구름

- 큰 중앙 봉우리 하나와 좌우의 작은 봉우리 2~3개만 사용한다.
- 좌우 끝의 뾰족한 꺾임과 지나치게 많은 잔봉우리를 없앤다.
- 아랫선은 거의 평평하되 모서리는 둥글게 처리해 통통한 스티커처럼 보이게 한다.

## 구현 순서

1. 새 실루엣의 핵심 좌표와 연결성을 검증하는 회귀 테스트를 먼저 추가한다.
2. `app/lib/masks.mjs`의 세 외곽선, 내부 안전 영역, 세부선을 함께 수정한다.
3. `app/components/QuickSettings.tsx`의 세 축소 아이콘을 동일한 조형 언어로 맞춘다.
4. `업데이트 내역`에 개선 날짜와 내용을 기록한다.
5. 단위 테스트·렌더링 테스트·린트·정적 빌드를 실행한다.
6. 실제 브라우저에서 나비·나뭇잎·구름을 20개와 100개 단어 상태로 확인하고, 390×812 모바일 폭과 콘솔 오류도 검사한다.

## 수용 기준

- 32~36px 아이콘에서도 세 마스크를 라벨 없이 구별할 수 있다.
- 나비는 네 날개와 몸통, 나뭇잎은 뾰족한 끝·잎자루·잎맥, 구름은 3~4개의 둥근 봉우리가 보인다.
- 100개 단어가 선택한 외곽선 밖으로 나가지 않는다.
- 내부 배치 영역은 각 마스크에서 하나로 연결되고 Canvas 외곽선 안에 완전히 포함된다.
- 데스크톱과 390×812에서 가로 스크롤이 없고 설정 버튼이 정상적으로 줄바꿈된다.
- 기존 마스크·폰트·색상·저장 기능 회귀가 없다.
